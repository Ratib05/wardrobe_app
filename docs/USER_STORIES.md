# User Stories — Personal Wardrobe App

## Wardrobe Management

- As a user, I want to add clothing with a photo so I can recognise items quickly.
- As a user, I want to import many photos at once so I can catalogue my wardrobe quickly, then find the items that still need details.
- As a user, I want to record clothing attributes so I can filter and organise my wardrobe.
- As a user, I want to edit item details when something changes.
- As a user, I want to archive items I no longer wear without permanently deleting them.
- As a user, I want to search and filter clothing to find suitable items quickly.

## Outfit Management

- As a user, I want to combine existing items into an outfit.
- As a user, I want to save and name outfits I like.
- As a user, I want to rate or favourite outfits so I can find good combinations again.
- As a user, I want to edit saved outfits when I change my wardrobe.

## Recommendations

- As a user, I want suggestions based on clothing I own.
- As a user, I want recommendations to account for occasions, seasons, colours, and formality.
- As a user, I want to understand why an outfit was recommended.
- As a user, I want to dismiss unsuitable recommendations.
- As a user, I want my explicit preferences and feedback to influence future rankings.

## Wardrobe Gaps and Wishlist

- As a user, I want to identify gaps that limit my outfit combinations.
- As a user, I want to understand how a potential purchase would improve my wardrobe.
- As a user, I want to save potential purchases to a wishlist.
- As a user, I want to mark wishlist items as purchased.
- As a user, I want to dismiss suggestions that are not relevant to me.

## Privacy and Data Management

- As a user, I want the app to work offline.
- As a user, I want my wardrobe data stored locally.
- As a user, I want to create a backup of my database and images.
- As a user, I want to restore a backup if I change devices or lose data.
- As a user, I want the app to warn me before restoring over existing data.
- As a user, I want missing photos to be reported without making the app unusable.

## Settings and Reliability

- As a user, I want database updates to preserve existing data when the app is upgraded.
- As a user, I want understandable error messages when an operation fails.
- As a user, I want to know whether a backup or restore completed successfully.
